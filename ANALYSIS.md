## 1. Что это за проект

**VIBECOMIX** — браузерный редактор макетов комиксов. Художник создаёт проект
(размер страницы, рамка, обводка, число страниц), режет страницу на фреймы,
настраивает толщину перегородок между ними «под давлением» (как нажим пера в
SAI), загружает в фреймы картинки слоями с параллаксом и экспортирует готовую
страницу одним самодостаточным HTML-файлом с живым параллаксом.

Происхождение — Google AI Studio (vibe-coding): `metadata.json` с
`requestFramePermissions`, `applet_access_history.json` с приложением
`VIBECOMIX`, сгенерированный ИИ документ архитектуры `PROJECT_CONTEXT.md`.

**Стек:** чистый JS (ES2020+), классические `<script>`, никаких зависимостей в
рантайме. Vite используется только как дев-сервер, сборка — свой `scripts/build.mjs` (копирование + минификация через esbuild).

## 2. Что было не так до восстановления (история)

- В Git был **только каркас**: 10 файлов, каталога `src/` нет, при этом
  `index.html` ссылался на `/src/main.tsx`.
- `npm run build` падал: `Failed to resolve /src/main.tsx`.
- `npm run lint` (`tsc --noEmit`) при этом был **зелёным** — проверять было
  нечего. Ровно этот ложный сигнал зафиксирован в конце `PROJECT_CONTEXT.md`:
  «Весь код успешно скомпилирован, линтер горит зеленым».
- Один коммит, удалений в истории нет → код не закоммитили, а не потеряли.

**Урок:** зелёный линтер без исходников — не признак здоровья проекта. Нужен
CI, который собирает артефакт, и тест, который открывает приложение.
