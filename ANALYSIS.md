## 1. Что это за проект

**VIBECOMIX** — браузерный **векторный редактор макетов комиксов и манги**
(«раскадровщик»): художник рисует панели произвольной формы, режет их «ножом»,
гнёт границы как кривые Безье, вкладывает изображения с точной обрезкой по
SVG-маске и получает обводку переменной толщины, имитирующую ручную тушь.

Косвенные признаки происхождения — это **экспорт приложения из Google AI Studio**
(vibe-coding):

| Признак                                                                                 | Где видно            |
| --------------------------------------------------------------------------------------- | -------------------- |
| Заголовок по умолчанию «My Google AI Studio App»                                        | `index.html`         |
| `metadata.json` с `requestFramePermissions` и `MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API` | `metadata.json`      |
| Переменные `GEMINI_API_KEY` / `APP_URL`, подставляемые рантаймом AI Studio              | `.env.example`       |
| Переключатели `DISABLE_HMR` для живых правок агентом                                    | `vite.config.ts`     |
| Сгенерированный ИИ документ архитектуры                                                 | `PROJECT_CONTEXT.md` |

**Стек:** Vite 6 + React 19 + TypeScript 5.8 + Tailwind v4 (`@tailwindcss/vite`) +
`@google/genai` 2.4 + `lucide-react` + `motion` + `jszip`; в зависимостях также
лежат `express`, `dotenv`, `tsx` — остатки серверного шаблона AI Studio.

**Состояние на GitHub:** публичный репозиторий, 1 коммит, 0 звёзд, нет issues и PR,
нет лицензии, нет топиков, описание — «Vector **intaractive** comic creator program»
(опечатка), README — 6 строк про локальный запуск.

## 2. 🔴 Главная проблема: исходного кода нет

Репозиторий — это **документация без продукта**. Каталога `src/` нет вообще,
хотя `index.html` подключает `/src/main.tsx`:

```
$ git ls-tree -r HEAD --name-only
.env.example  .gitignore  PROJECT_CONTEXT.md  README.md
index.html    metadata.json  package-lock.json  package.json
tsconfig.json vite.config.ts          # ← 10 файлов, src/ отсутствует
```

Проверка сборки (зависимости установлены, Node 22):

```
$ npm run build
[vite:build-html] Failed to resolve /src/main.tsx from /home/user/VIBECOMIX/index.html
✗ Build failed in 50ms
```

А `npm run lint` (`tsc --noEmit`) проходит **зелёным** — просто потому, что
проверять нечего: в `tsconfig.json` нет `include`, и компилятор видит один
`vite.config.ts`. Это создаёт ложное чувство безопасности — ровно то, о чём
говорится в конце `PROJECT_CONTEXT.md`: _«Весь код успешно скомпилирован, линтер
горит зеленым»_. На самом деле кода нет.

В истории всего один коммит, и он не содержит удалённых файлов — то есть код
**никогда не был закоммичен**, а не потерян впоследствии. Вероятно, проект
разрабатывался внутри AI Studio, а в Git уехал только каркас.

**Вывод:** пока `src/` не восстановлен, любой другой апгрейд вторичен.
