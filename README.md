# VIBECOMIX

**Векторный интерактивный редактор макетов комиксов и манги.**

VIBECOMIX — это браузерный инструмент для раскладки страниц комикса: вы рисуете
панели произвольной формы, режете их «ножом», гнёте границы как кривые Безье,
вкладываете изображения в панели с точной обрезкой по SVG-маске и получаете
«живую» обводку переменной толщины, имитирующую работу тушью.

> ⚠️ **Статус: альфа / исходный код отсутствует.**
> В репозитории на данный момент лежит только каркас (конфиги Vite/TS/Tailwind и
> описание архитектуры). Каталог `src/` не закоммичен, поэтому `npm run build`
> падает. Подробности — в [ANALYSIS.md](./ANALYSIS.md).

EN: VIBECOMIX is an in‑browser vector layout tool for comic/manga pages — custom
polygon panels, a knife tool, Bézier borders, SVG clipping masks and
pressure‑based variable‑width inking. Currently the repository ships scaffolding
only; the application source (`src/`) is missing.

## Возможности (по задумке, см. [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md))

| Возможность               | Описание                                                                                         |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| Панели произвольной формы | Прямоугольники и кастомные многоугольники с вершинами и кривыми Безье (`handleIn` / `handleOut`) |
| Инструмент «нож»          | Разрезает панель по линии на две векторные фигуры, распределяя внутренние слои                   |
| Трансформации панели      | Сдвиг, масштаб и поворот целой панели без изменения базовых вершин                               |
| Давление пера             | Множитель толщины на каждую вершину → сужающиеся линии туши (0.1–5.0)                            |
| Обрезка слоёв             | `<clipPath>` на кадр + контуры обводки в общестраничном SVG-оверлее                              |
| Мультистраничность        | Несколько страниц в одном проекте, настраиваемые поля и gutters                                  |
| Undo / Redo               | `Ctrl+Z`, `Ctrl+Y` / `Ctrl+Shift+Z`; удаление — `Delete` / `Backspace` / `X`                     |

## Локальный запуск

**Требования:** Node.js >= 20 и npm.

```bash
npm install            # установка зависимостей
cp .env.example .env.local
# впишите свой ключ в GEMINI_API_KEY (см. раздел «Безопасность ключа»)
npm run dev            # http://localhost:3000
```

| Команда           | Назначение                           |
| ----------------- | ------------------------------------ |
| `npm run dev`     | Дев-сервер Vite на `0.0.0.0:3000`    |
| `npm run build`   | Продакшн-сборка в `dist/`            |
| `npm run preview` | Предпросмотр собранной версии        |
| `npm run lint`    | Проверка типов: `tsc --noEmit`       |
| `npm run format`  | Prettier — форматирование исходников |

## Безопасность ключа Gemini

`@google/genai` можно вызывать как напрямую из браузера, так и через сервер.
Прямой вызов из фронтенда **раскрывает ключ любому посетителю страницы**.
Для публичного деплоя используйте тонкий прокси на Express (зависимость уже
подключена), который читает `GEMINI_API_KEY` из окружения и проксирует запросы.
Никогда не коммитьте `.env.local` — он исключён в `.gitignore`.
