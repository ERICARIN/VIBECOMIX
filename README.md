# VIBECOMIX

**Векторный редактор макетов комиксов: режь страницу на фреймы, настраивай
перегородки «под давлением», раскладывай картинки слоями и отдавай готовую
страницу с параллаксом одним HTML-файлом.**

![статус: восстановлено из архива](https://img.shields.io/badge/status-restored-green)

> **Важно.** Проект разрабатывался в Google AI Studio, и в Git долгое время
> лежал только каркас — исходники не были закоммичены. Код найден на Google
> Диске (`vibecomix_modular/`) и восстановлен в этом репозитории. Подробности —
> в [ANALYSIS.md](./ANALYSIS.md).

## Возможности

|                      |                                                                                                                                                                                                                                      |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Фреймы**           | Страница делится на фреймы кнопками-полукнопками по центру каждой стороны; фрейм можно удалить (сосед автоматически поглощает место)                                                                                                 |
| **Перегородки**      | Толщина и обводка каждой границы настраиваются перетаскиванием и колесом мыши: перетаскивание + колесо = «давление» на перегородку, `Ctrl` + колесо = обводка, `Shift` + колесо = рамка листа, `Shift+Ctrl` + колесо = обводка листа |
| **Слои**             | В каждый фрейм загружаются картинки (включая GIF), у слоя есть смещение, масштаб, поворот, скрытие и **параллакс** (0–100)                                                                                                           |
| **Страницы**         | Мультистраничный проект, миниатюры в сайдбаре, перетаскивание страниц, свой размер у каждой страницы                                                                                                                                 |
| **Холст**            | Зум и панорамирование, ручное изменение размера страницы (8 ручек по краям), авто-вписывание                                                                                                                                         |
| **Отмена**           | Undo/Redo на 30 шагов: `Ctrl+Z` / `Ctrl+Shift+Z` (`Ctrl+Y`)                                                                                                                                                                          |
| **Превью и экспорт** | Превью с живым параллаксом по движению мыши и экспорт в **один самодостаточный HTML-файл** (без зависимостей)                                                                                                                        |

## Запуск

Приложение — статический сайт **без npm-зависимостей в рантайме**: никаких
ключей API, сборщиков и серверов не требуется.

```bash
# вариант 1: dev-сервер Vite с живой перезагрузкой (нужен Node.js >= 20)
npm install
npm run dev        # http://localhost:3000

# вариант 2: вообще без Node.js — любой статический сервер
python3 -m http.server 8080   # затем http://localhost:8080
# или VS Code → расширение Live Server → Open with Live Server
```

Классические `<script>` требуют именно http-сервера: при открытии
`index.html` как файла (`file://`) браузер часть возможностей заблокирует.

| Команда           | Что делает                                                                              |
| ----------------- | --------------------------------------------------------------------------------------- |
| `npm run dev`     | Дев-сервер Vite на `0.0.0.0:3000`                                                       |
| `npm run build`   | Собирает `dist/` (копирует статику, минифицирует JS через esbuild)                      |
| `npm run preview` | Отдаёт собранный `dist/`                                                                |
| `npm test`        | Дымовой тест редактора в jsdom: создать → разрезать → undo → удалить → превью → экспорт |
| `npm run lint`    | Проверка типов (`tsc --noEmit`)                                                         |
| `npm run format`  | Prettier для конфигов, скриптов и документации                                          |

## Структура

```
index.html        — разметка и ПОРЯДОК подключения скриптов (он важен!)
style.css         — весь CSS
js/
  state.js        — состояние S, mkFrame/mkLayer, undo/redo, горячие клавиши
  dialog.js       — диалог создания проекта
  viewport.js     — холст: зум, пан, размер страницы, топбар
  sidebar.js      — страницы, миниатюры, drag-reorder
  dividers.js     — перегородки: render + drag + wheel + renderPage()
  frames.js       — renderFrame, splitFrame, deleteFrame
  layers.js       — слои, трансформация картинок, панель слоёв, загрузка
  preview.js      — превью с параллаксом и экспорт HTML
scripts/build.mjs — статическая сборка в dist/
tests/smoke.mjs   — дымовой тест в jsdom
```

Полная карта «что где менять» — в [CONTRIBUTING.md](./CONTRIBUTING.md).

## Как это работает

- Всё состояние живёт в одном объекте `S` (`js/state.js`), доступном всем
  модулям: скрипты подключены классическими тегами и делят глобальную область
  видимости.
- `renderPage()` (`js/dividers.js`) — главная функция перерисовки; её вызывают
  после любого изменения данных.
- `snapshot()` (`js/state.js`) — положить текущее состояние в историю undo
  (глубина 30 шагов).

## Известные ограничения

- Нет сохранения проекта: перезагрузка страницы теряет работу (только undo внутри сессии).
- Экспорт только в HTML; PNG/PDF/SVG пока нет.
- Картинки хранятся в памяти как data-URL — на больших проектах расходуется много памяти.
- Нельзя резать фрейм по произвольной линии («нож») — только пополам по горизонтали/вертикали.

Полный разбор и план развития — в [ANALYSIS.md](./ANALYSIS.md).
