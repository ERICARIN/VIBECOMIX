## 🚀 1. Обзор и миссия
Это приложение представляет собой высокооптимизированный интерактивный профессиональный **Инструмент для создания бесконечных кадров комиксов и макетов манги**. Оно позволяет художникам комиксов и раскадровщикам визуально проектировать пользовательские макеты страниц, разрезать панели с помощью инструмента «нож» в реальном времени, изменять границы кадров как редактируемые векторные кривые с анкерами Безье, локально настраивать толщину обводки с помощью веса нажима и помещать оверлеи изображений внутрь границ панелей с точными путями кадрирования (clipping paths) на основе SVG.

## 📐 3. Модель данных и типы (`types.ts`)
Приложение строго типизировано для обеспечения высокой точности. Ключевые конструкции:

* **`Layer`**: Отдельный оверлей изображения, загруженный в кадр. Имеет размеры, смещение (`tx`, `ty`), масштаб (`scale`), поворот, непрозрачность и иерархию в стеке слоев.
* **`Frame`**: Панель комикса.
    * Может быть стандартным прямоугольником или сложным кастомным векторным многоугольником.
    * **Vertices (Вершины)**: Массив абсолютных точек, представляющих координаты относительно сетки страницы.
    * **Атрибуты кривых Безье**: Вершины расширены поддержкой `handleIn?: Point`, `handleOut?: Point` и логического значения `isCurve?: boolean` для моделирования плавных кривых.
    * **Трансформации**: Поддерживает локальные параметры кадра `tx` (смещение по X), `ty` (смещение по Y), `scale` (масштаб), `rotate` (поворот) для сдвига/поворота/масштабирования всей векторной фигуры без изменения базовых индексов вершин. Это обеспечивает плавное перетаскивание, масштабирование колесиком мыши и настройку целых панелей!
    * **Давление на вершины**: Массив числовых множителей (от `0.1` до `5.0`), привязанных к каждой вершине для рендеринга сужающихся линий туши, имитирующих ручную работу.
* **`Page`**: Набор кадров, представляющих страницу. Рабочая область поддерживает многостраничную раскадровку.
* **`AppState`**: Хранит текущую ширину, высоту, общие отступы границ, резервные контуры обводки, фактический список `pages` и указатель на `currentPage`.

## 🧮 4. Ключевые математические и SVG-движки (`geometry.ts`)

### A. Трансформации координат
* **`getTransformedVertices(fr: Frame)`**: Берет базовые вершины и применяет значения масштаба `scale`, поворота `rotate` и смещения (`tx`, `ty`) относительно геометрического центра ограничивающей рамки (bounding box) многоугольника. Также поворачивает смещения управляющих точек Безье, чтобы направляющие линии выравнивались без швов.
* **`getSvgPathFromVertices(vertices)`**: Преобразует список вершин (с управляющими точками `handleIn`/`handleOut` или без них) в стандартные строки определения путей кубических кривых Безье SVG `M ... C ... Z`.
* **`getAdjustedVertices(fr, pw, ph, stateBorderWidth, pageBorderWidth)`**: Вычисляет конечные координаты рисования с учетом межпанельных промежутков (gutters) для конкретного кадра или всей страницы (чтобы гарантировать, что отступы выглядят чистыми и выровненными).

### B. Маски кадрирования и высокоточный рендеринг
Чтобы избежать выхода контента за пределы векторных панелей сложной формы, в каждом кадре используется двухкомпонентная система рендеринга:
1.  **Маска контента DOM**: Инлайновый локальный `<svg>`, определяющий `<clipPath id="clip-[frame-id]">` с `<path d={clipPathD} />`, сгенерированным через `getSvgPathFromVertices`. Эта маска корректно обрезает слои внутри HTML-границ.
2.  **Слой контура обводки**: Чтобы края обводки не обрезались ограничениями DOM-контейнера, мы рисуем контуры внутри **общестраничного оверлейного SVG-контекста**.

### C. Продвинутое сужение штриха под ручную графику
Движок контуров разбивает кривые на множество сегментов (сэмплов). Он вычисляет перпендикулярные векторы смещения (нормали) для каждой точки и интерполирует веса давления (`vertexPressures`) для генерации сегментов многоугольника переменной толщины (`<polygon points="..." />`) со скругленными краями для красивого, органичного вида живой туши.

## 🎮 5. Конечный автомат рабочей области и режимы взаимодействия (`Workspace.tsx`)
Компонент `Workspace` управляет интерактивными режимами инструментов:
* **Режим `select` (Выделение)**:
    * Одиночный клик выбирает панель и фокусирует стек ее слоев.
    * Двойной клик включает трансформацию слоев или перетаскивание внутренних объектов.
    * Удерживание левой кнопки мыши перемещает координаты всего кадра (`tx`, `ty`).
    * Прокрутка колесика мыши над активным кадром изменяет его масштаб (`scale`).
    * Shift + колесико мыши поворачивает кадр (`rotate`).
* **Режим `knife` (Нож)**:
    * Проведите линию разреза через панель.
    * Разделяет любой кадр, пересекаемый линией разреза, на два кастомных векторных многоугольника, аккуратно распределяя внутренние слои.
* **Режим `vertex` (Вершины)**:
    * Обычное лассо выделения позволяет выбирать вершины.
    * Перетаскивание позиций вершин изменяет контур панели.
    * Клик по выбранной вершине показывает **касательные управляющие маркеры Безье** (отображаются в виде пунктирных линий). Их перетаскивание изменяет векторы направляющих, динамически искривляя грани панелей!
* **Режим `pressure` (Давление/Нажим)**:
    * Выберите вершины и перетаскивайте специальные радиальные круги-маркеры веса, чтобы изменять кастомные контуры кисти в реальном времени.

### Горячие клавиши, зарегистрированные на активном листе:
* `Ctrl + Z` и `Ctrl + Y` (или Shift + Z): Быстрый Undo и Redo.
* `Delete`, `Backspace` или `X` (работает как на английской, так и на русской раскладке):
    * Удаляет активные слои внутри активной панели.
    * Если ни один слой не выделен, удаляет подсвеченный кадр комикса.
